
# Excel for Data Analysis — Practical Examples Roadmap

## Overview

This roadmap provides a structured learning path for data analysis using Microsoft Excel, XLStat, and Minitab.

The learning materials are organized into two sessions:

- **Session 01:** Excel Fundamentals and Basic Statistical Analysis
- **Session 02:** Advanced Statistical Analysis with Excel and XLStat

Each topic includes practical examples, formulas, exercises, and interpretation guidance.

# Final Project — Employee Salary Data Analysis

**Objective:** Perform a complete statistical analysis of an employee dataset.

## Project Steps

1. Import the dataset.
2. Clean and organize the data.
3. Perform descriptive statistics.
4. Calculate quartiles and percentiles.
5. Detect potential outliers.
6. Standardize and normalize numerical variables.
7. Conduct normality tests.
8. Analyze Pearson and point-biserial correlations where appropriate.
9. Create Scatter Plots and Box Plots.
10. Interpret the results and prepare a final report.

## Tools

- Microsoft Excel
- XLStat
- Minitab
