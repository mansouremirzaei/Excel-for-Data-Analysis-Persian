# Excel for Data Analysis — Persian Learning Notes

## About This Repository

This repository contains Persian educational notes, practical examples, and exercises for learning data analysis using Microsoft Excel.

The main purpose of this project is to review Excel concepts, document analytical techniques, and develop practical data analysis skills through structured learning materials.

## Learning Topics

The repository covers the following topics:

- Excel Fundamentals
- Data Preparation and Data Management
- Excel Formulas and Functions
- Sorting and Filtering
- Data Visualization
- Descriptive Statistics
- Statistical Analysis
- Data Analysis with Excel Add-ins

## Learning Approach

Each topic is documented using the following structure:

1. Concept Explanation
2. Excel Functions and Formulas
3. Practical Examples
4. Screenshots
5. Practice Exercises

## Language

The educational explanations are primarily in Persian, while technical terms, file names, and Excel functions are presented in English.

## Tools

- Microsoft Excel
- XStat / XLStat (where applicable)
