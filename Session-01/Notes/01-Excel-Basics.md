## 1. Introduction to Excel

Microsoft Excel is a spreadsheet application used for organizing, managing, calculating, and analyzing data.

اکسل یک نرم‌افزار صفحه‌گسترده است که برای سازمان‌دهی داده‌ها، انجام محاسبات، مدیریت اطلاعات و تحلیل داده‌ها استفاده می‌شود.

در تحلیل داده، Excel می‌تواند برای موارد زیر به کار رود:

- Data Organization
- Data Cleaning
- Statistical Analysis
- Data Visualization
- Data Management

## 2. Excel Worksheet Structure

محیط Excel از سطرها و ستون‌ها تشکیل شده است.

| Component | Description |
|---|---|
| Row | سطرهای افقی که با اعداد مشخص می‌شوند |
| Column | ستون‌های عمودی که با حروف مشخص می‌شوند |
| Cell | محل تقاطع یک سطر و یک ستون |
| Cell Address | آدرس یک سلول که از حرف ستون و شماره سطر تشکیل می‌شود |
| Worksheet | صفحه کاری شامل سطرها و ستون‌ها |
| Workbook | فایل Excel که می‌تواند شامل چند Worksheet باشد |

### Example

سلول `B3` به معنی سلولی است که در ستون B و سطر 3 قرار دارد.

## 3. Navigating Between Cells

برای جابه‌جایی سریع در محیط Excel می‌توان از کلیدهای میانبر استفاده کرد.

| Keyboard Shortcut | Function |
|---|---|
| Tab | حرکت به سلول بعدی در همان سطر |
| Enter | حرکت به سلول بعدی در جهت پایین |
| Shift + Tab | حرکت به سلول قبلی |
| Shift + Enter | حرکت به سلول بالایی |
| Ctrl + Home | رفتن به ابتدای Worksheet |
| Alt + Enter | ایجاد خط جدید داخل یک سلول |

### Practical Example

فرض کنید در حال وارد کردن اطلاعات یک جدول هستیم.

با فشردن Tab می‌توانیم اطلاعات را در سلول‌های بعدی همان سطر وارد کنیم.

با فشردن Enter می‌توانیم به سطر بعدی برویم.

این روش ورود اطلاعات را سریع‌تر و منظم‌تر می‌کند.

## 5. Number Formatting

Number Formatting مشخص می‌کند که داده‌های عددی چگونه در سلول نمایش داده شوند.

برای مثال، یک مقدار عددی می‌تواند به شکل عدد معمولی، درصد، واحد پول یا تاریخ نمایش داده شود.

### General Format

فرمت General قالب پیش‌فرض Excel برای نمایش داده‌ها است.

### Percentage Format

فرمت Percentage برای نمایش مقادیر به‌صورت درصد استفاده می‌شود.

### Currency and Accounting Format

این قالب‌ها برای نمایش مقادیر مالی و پولی استفاده می‌شوند.

### Important Note

Number Formatting معمولاً نحوه نمایش داده را تغییر می‌دهد، نه مقدار اصلی ذخیره‌شده در سلول.

## 7. Key Takeaways

- Excel is a spreadsheet application for data management and analysis.
- A cell is identified by its column letter and row number.
- Keyboard shortcuts improve data entry efficiency.
- The Home Tab provides essential formatting tools.
- Number Formatting controls how values are displayed.
