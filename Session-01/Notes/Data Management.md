# مدیریت داده‌ها (Data Management)

## اهداف یادگیری (Learning Objectives)

در پایان این بخش، می‌توانید یک جدول داده‌ای تمیز، منظم و یکپارچه آماده کنید که برای تحلیل داده‌ها مناسب باشد.

---

## ۱. ساختار استاندارد جدول داده‌ها (Recommended Table Structure)

برای اینکه داده‌ها به‌درستی در اکسل تحلیل شوند، باید ساختار جدول استاندارد باشد.

اصول ساختاردهی جدول:

- هر سطر (Row) باید نمایانگر یک رکورد (Record) باشد.
- هر ستون (Column) باید نمایانگر یک متغیر (Variable) باشد.
- جدول باید فقط یک ردیف عنوان (Header Row) داشته باشد.
- از ادغام سلول‌ها (Merged Cells) در داخل مجموعه داده خودداری کنید.
- نام ستون‌ها باید واضح، یکتا و توصیفی باشند.

### مثال کاربردی

| EmployeeID | Employee | Department | Salary |
| ---------- | -------- | ---------- | -----: |
| 101        | Sara     | Sales      |  32000 |
| 102        | Ali      | IT         |  41000 |
| 103        | Mina     | Sales      |  35000 |
| 104        | Reza     | HR         |  29000 |

در این جدول:

- هر سطر اطلاعات یک کارمند را نشان می‌دهد.
- `EmployeeID` شناسه یکتای کارمند است.
- `Employee` نام کارمند را مشخص می‌کند.
- `Department` واحد سازمانی را نشان می‌دهد.
- `Salary` حقوق کارمند را نمایش می‌دهد.

**نکته:** ساختار استاندارد داده‌ها باعث می‌شود ابزارهایی مانند `Sort`، `Filter`، `PivotTable` و توابع تحلیلی اکسل بهتر عمل کنند.

---

## ۲. مرتب‌سازی و فیلتر کردن داده‌ها (Sort and Filter)

دو ابزار مهم برای بررسی و مدیریت داده‌ها در اکسل عبارت‌اند از:

- `Sort`: مرتب‌سازی داده‌ها
- `Filter`: فیلتر کردن داده‌ها

### الف) مرتب‌سازی داده‌ها (Sort)

مرتب‌سازی، ترتیب قرارگیری سطرها را بر اساس یک ستون تغییر می‌دهد.

مثال:

مرتب‌سازی ستون `Salary` از بزرگ‌ترین مقدار به کوچک‌ترین مقدار:

`Data → Sort`

پس از مرتب‌سازی، کارکنان با حقوق بالاتر در ابتدای جدول قرار می‌گیرند.

### ب) فیلتر کردن داده‌ها (Filter)

فیلتر کردن، سطرهایی را نمایش می‌دهد که با شرط مشخص‌شده مطابقت دارند و سایر سطرها را موقتاً پنهان می‌کند.

مسیر فعال‌سازی:

`Data → Filter`

### مثال‌های فیلتر

**مثال ۱ — نمایش کارکنان واحد فروش**

در ستون `Department`، فقط مقدار `Sales` را انتخاب کنید.

**مثال ۲ — نمایش کارکنان با حقوق بیشتر از 30,000**

در ستون `Salary`، شرط زیر را اعمال کنید:

`Number Filters → Greater Than → 30000`

### تفاوت Sort و Filter

| ابزار  | عملکرد                                 |
| ------ | -------------------------------------- |
| Sort   | ترتیب سطرها را تغییر می‌دهد.           |
| Filter | سطرهای نامنطبق با شرط را پنهان می‌کند. |

**نکته مهم:** فیلتر کردن، داده‌ها را حذف نمی‌کند؛ فقط برخی سطرها را از نمایش موقت خارج می‌کند.

## ۳. پاک‌سازی اولیه داده‌ها (Basic Data Cleaning)

پاک‌سازی داده‌ها (Data Cleaning) یکی از مراحل مهم پیش از تحلیل داده است.

داده‌های نامنظم، دارای مقادیر گمشده یا ناسازگار می‌توانند باعث نتایج نادرست در تحلیل شوند.

### الف) حذف داده‌های تکراری (Remove Duplicates)

برای حذف رکوردهای تکراری از ابزار زیر استفاده کنید:

`Data → Remove Duplicates`

**نکته:** قبل از حذف رکوردهای تکراری، باید مشخص کنید چه چیزی یک رکورد را تکراری محسوب می‌کند.

برای مثال، اگر `EmployeeID` شناسه یکتای هر کارمند باشد، تکرار آن می‌تواند نشانه وجود رکورد تکراری باشد. اما تکرار نام به‌تنهایی لزوماً به معنای تکراری بودن رکورد نیست.

### ب) شناسایی سلول‌های خالی (Identify Blank Cells)

برای شمارش سلول‌های خالی در محدوده حقوق کارکنان:

`=COUNTBLANK(D2:D100)`

این تابع تعداد سلول‌های خالی در محدوده `D2:D100` را محاسبه می‌کند.

### ج) حذف فاصله‌های اضافی (Remove Extra Spaces)

گاهی نام افراد به دلیل ورود داده‌ها دارای فاصله اضافی است.

برای حذف فاصله‌های اضافی از تابع `TRIM` استفاده کنید:&#x20;

`=TRIM(B2)`

این تابع فاصله‌های اضافی ابتدا و انتهای متن و فاصله‌های تکراری میان کلمات را حذف می‌کند.

**نکته:** تابع `TRIM` معمولاً فاصله‌های معمولی را پاک‌سازی می‌کند؛ برخی فاصله‌های خاص مانند Non-breaking Space ممکن است نیازمند پاک‌سازی جداگانه باشند.

### د) یکسان‌سازی دسته‌ها (Standardize Category Labels)

ممکن است نام یک واحد سازمانی به شکل‌های مختلف وارد شده باشد:

| مقدار اولیه |
| ----------- |
| sales       |
| Sales       |
| SALES       |

این مقادیر از نظر نوشتاری متفاوت‌اند، اما ممکن است همگی به یک واحد سازمانی اشاره کنند.

پیش از گروه‌بندی و تحلیل، دسته‌ها را به یک شکل استاندارد تبدیل کنید.

برای مثال:

`Sales`

**نکته:** توابع مقایسه متن در اکسل معمولاً به بزرگی و کوچکی حروف حساس نیستند؛ با این حال، یکسان‌سازی برچسب‌ها برای کیفیت داده و گزارش‌دهی اهمیت دارد.

### هـ) بررسی نوع داده‌ها (Check Data Types)

اطمینان حاصل کنید که تاریخ‌ها و اعداد واقعاً به‌صورت عددی یا Date ذخیره شده‌اند، نه به شکل Text.

برای مثال:

| مقدار      | نوع مناسب |
| ---------- | --------- |
| 32000      | Number    |
| 2026/11/09 | Date      |
| 41000      | Number    |

اگر اعداد یا تاریخ‌ها به‌صورت Text ذخیره شوند، ممکن است در محاسبات، مرتب‌سازی یا تحلیل آماری مشکل ایجاد کنند.

## ۴. محاسبات شرطی (Conditional Calculations)

توابع شرطی امکان محاسبه روی داده‌هایی را فراهم می‌کنند که یک شرط مشخص را برآورده می‌کنند.

در این بخش از توابع زیر استفاده می‌کنیم:

- `COUNTIF`
- `SUMIF`
- `AVERAGEIF`
- `IF`

### الف) شمارش کارکنان واحد فروش — COUNTIF

تابع `COUNTIF` تعداد سلول‌هایی را می‌شمارد که با یک شرط مشخص مطابقت دارند.

ساختار:

`=COUNTIF(range,criteria)`

فرمول:

`=COUNTIF(C2:C5,"Sales")`

نتیجه:

`2`

زیرا دو کارمند در واحد `Sales` فعالیت می‌کنند.

### ب) محاسبه مجموع حقوق کارکنان واحد فروش — SUMIF

تابع `SUMIF` مجموع مقادیر را بر اساس یک شرط محاسبه می‌کند.

ساختار:

`=SUMIF(range,criteria,sum_range)`

فرمول:

`=SUMIF(C2:C5,"Sales",D2:D5)`

محاسبه:

`32000 + 35000 = 67000`

نتیجه:

`67000`

### ج) محاسبه میانگین حقوق کارکنان واحد فروش — AVERAGEIF

تابع `AVERAGEIF` میانگین مقادیر را بر اساس یک شرط محاسبه می‌کند.

فرمول:

`=AVERAGEIF(C2:C5,"Sales",D2:D5)`

محاسبه:

`(32000 + 35000) / 2 = 33500`

نتیجه:

`33500`

### د) دسته‌بندی حقوق کارکنان — IF

تابع `IF` برای بررسی یک شرط و بازگرداندن نتیجه متفاوت بر اساس درست یا نادرست بودن شرط استفاده می‌شود.

ساختار:

`=IF(logical_test,value_if_true,value_if_false)`

در سلول `E2` فرمول زیر را وارد کنید:

`=IF(D2>=40000,"High","Standard")`

تفسیر:

- اگر حقوق کارمند حداقل 40,000 باشد، نتیجه `High` خواهد بود.
- اگر حقوق کارمند کمتر از 40,000 باشد، نتیجه `Standard` خواهد بود.

### جدول نتایج

| Employee | Department | Salary | Salary Label |
| -------- | ---------- | -----: | ------------ |
| Sara     | Sales      |  32000 | Standard     |
| Ali      | IT         |  41000 | High         |
| Mina     | Sales      |  35000 | Standard     |
| Reza     | HR         |  29000 | Standard     |

## ۵. تمرین‌های عملی (Practice)

### تمرین ۱ — فیلتر کردن واحد IT

جدول کارکنان را فیلتر کنید تا فقط کارکنان واحد `IT` نمایش داده شوند.

### تمرین ۲ — شمارش حقوق‌های گمشده

تعداد رکوردهایی را که مقدار حقوق آن‌ها خالی است، با استفاده از `COUNTBLANK` محاسبه کنید.

### تمرین ۳ — دسته‌بندی حقوق

با استفاده از تابع `IF`، حقوق کارکنان را در دو گروه قرار دهید:

- `High`: حقوق برابر یا بیشتر از 40,000
- `Standard`: حقوق کمتر از 40,000

### تمرین ۴ — بررسی رکوردهای تکراری

رکوردهای تکراری جدول را شناسایی کنید.

قبل از حذف، مشخص کنید که معیار تکراری بودن چیست و توضیح دهید چرا آن رکورد را حذف کرده‌اید.

## ۶. چک‌لیست کیفیت داده‌ها (Data Quality Checklist)

قبل از شروع تحلیل، موارد زیر را بررسی کنید:

- [ ] شناسه یکتای رکورد وجود دارد.
- [ ] عنوان ستون‌ها یکتا و توصیفی هستند.
- [ ] مقادیر گمشده بررسی شده‌اند.
- [ ] دسته‌بندی‌ها دارای املای یکسان هستند.
- [ ] ستون‌های عددی و تاریخ دارای نوع داده صحیح هستند.
- [ ] رکوردهای تکراری با معیار مشخص بررسی شده‌اند.
- [ ] مرتب‌سازی و فیلتر کردن باعث حذف ناخواسته رکوردها نشده است.

---

## ۷. نکات کلیدی (Key Takeaways)

- ساختار استاندارد جدول، تحلیل داده‌ها را ساده‌تر و دقیق‌تر می‌کند.
- هر سطر باید یک رکورد و هر ستون باید یک متغیر را نمایش دهد.
- `Sort` ترتیب داده‌ها را تغییر می‌دهد؛ `Filter` سطرهای نامنطبق را پنهان می‌کند.
- پاک‌سازی داده‌ها باید قبل از تحلیل انجام شود.
- `COUNTBLANK` تعداد سلول‌های خالی را محاسبه می‌کند.
- `TRIM` برای حذف فاصله‌های اضافی در متن استفاده می‌شود.
- `COUNTIF` برای شمارش شرطی، `SUMIF` برای جمع شرطی و `AVERAGEIF` برای میانگین شرطی کاربرد دارند.
- `IF` برای دسته‌بندی داده‌ها بر اساس شرط استفاده می‌شود.
- حذف داده‌های تکراری باید با معیار مشخص و منطقی انجام شود.
